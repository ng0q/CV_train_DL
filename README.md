# CV_train_DL

Проект для обучения моделей computer vision (CIFAR-10 и связанные эксперименты).

## Структура

- `app/` — приложение / инференс
- `model/` — сохранённые веса моделей
- `data/` — датасеты (не коммитятся)
- `notebook/` — Jupyter-ноутбуки с экспериментами

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
